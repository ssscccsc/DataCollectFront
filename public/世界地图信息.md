# 世界地图功能信息

## 📍 地图概述

仪表盘中的世界地图用于可视化展示数据采集任务的地域分布情况。地图支持显示城市和国家标记，并可查看各地区的统计数据。

## 🗺️ 地图特性

### 1. 数据来源
- **地图数据**：从 `public/world.json` 本地加载（GeoJSON格式）
- **地域标记**：从后端API获取（`/region/level/4` 和 `/region/level/2`）
- **统计数据**：双击标记点后从 `/dashboard/region-stats` 获取

### 2. 标记点类型
- **城市标记**（蓝色圆点）：显示level=4的地域（城市）
- **国家标记**（蓝色圆点）：显示level=2的地域（国家）

### 3. 坐标映射
当前支持的城市坐标映射（30+个）：
- 中国主要城市：北京、上海、广州、深圳、杭州、南京、武汉、成都、西安等
- 坐标格式：[经度, 纬度]

当前支持的国家坐标映射（13个）：
- 主要国家：中国、美国、日本、韩国、英国、法国、德国等

## 📊 统计功能

双击地图上的城市或国家标记，会弹出统计对话框显示：

| 统计项 | 说明 |
|--------|------|
| **采集的APP数量** | 该地域下所有采集任务关联的不同APP数量（去重） |
| **采集次数** | 该地域下所有采集任务的采集次数总和 |
| **执行机数量** | 该地域下的执行机总数 |

## 🎨 地图样式

- **背景色**：#fafafa
- **国家边界**：浅灰色 (#d0d0d0)
- **国家填充**：浅灰色 (#e7e7e7)
- **标记点颜色**：#409EFF（蓝色）
- **标记点大小**：12px
- **标记点标签**：显示地域名称

## 🔧 技术实现

### 前端技术栈
- **ECharts 5.4.3**：地图渲染
- **Vue 3**：组件框架
- **地理坐标系**：使用geo组件或散点图模式

### 后端API

#### 1. 获取地域列表
```
GET /region/level/4  # 获取所有城市
GET /region/level/2  # 获取所有国家
```

#### 2. 获取地域统计
```
GET /dashboard/region-stats?regionId={id}
```

**响应示例：**
```json
{
  "code": 200,
  "data": {
    "regionName": "北京",
    "level": 4,
    "appCount": 5,
    "collectCount": 120,
    "executorCount": 3
  }
}
```

## 🔄 数据加载流程

1. **页面加载** → 初始化ECharts地图实例
2. **加载地图数据** → 从 `/world.json` 读取GeoJSON数据
3. **注册地图** → 使用 `echarts.registerMap()` 注册
4. **加载地域数据** → 获取城市和国家列表
5. **坐标映射** → 将地域名称映射到经纬度坐标
6. **渲染标记** → 在地图上显示标记点
7. **绑定事件** → 监听双击事件，显示统计信息

## ⚠️ 注意事项

1. **地图数据**：如果 `world.json` 为空或不存在，将使用散点图模式（仍然可用）
2. **坐标映射**：只有在地图坐标映射表中的城市/国家才会显示标记
3. **数据过滤**：只显示 `status=1` 且 `deleted=0` 的地域记录

## 🚀 扩展建议

1. **扩展坐标映射**：可以添加更多城市的经纬度坐标
2. **使用地理编码API**：自动获取城市坐标，无需手动维护映射表
3. **地图交互**：可以添加筛选、搜索等功能
4. **热力图**：根据采集任务数量显示热力图
